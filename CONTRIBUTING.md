# Contributing

Contributions should strengthen a documented claim, invariant, experiment, or reviewer path. Open an issue before proposing a new trusted component or external adapter.

## Development

```bash
make bootstrap
make lint
make typecheck
make test
make security
```

Every security-critical change must include tests that fail when the relevant check is removed or inverted. New evaluation results must be generated by the repository and committed with a verifiable evidence manifest; do not hand-edit metrics. Significant trust-boundary decisions require an ADR.

Keep all experiments synthetic and local. See [SECURITY.md](SECURITY.md) before adding test cases.

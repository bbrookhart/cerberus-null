# ADR-007: Consequence and blast-radius taxonomy

- Status: Accepted
- Date: 2026-08-26

## Decision

Assign every action a T0–T4 consequence tier and B0–B5 blast radius, plus reversibility and mission impact. T4 has no autonomous executable path in v0.1.

## Consequences

Policy reasons about operational effect, not only permission strings, and evaluation can separate attempted from realized consequence.

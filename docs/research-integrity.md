# Research integrity

All environments, identities, resources, adversarial instructions, tool responses, memory entries, approvals, and consequences in CERBERUS NULL are simulated. No experiment requires or authorizes contact with a production system.

Model failure is measured separately from proposal, authorization, execution, and consequence. A blocked malicious proposal is a model-layer failure contained by the system boundary; it is not reported as a safe model response. Conversely, a safe model response does not prove the boundary works.

Committed metrics are generated by executable code and bound by a verifiable manifest. They must never be hand-edited. Absence of a bypass in the suite is not proof that none exists. Framework crosswalks do not establish compliance. No certification, formal proof, agency endorsement, or government affiliation is claimed.
